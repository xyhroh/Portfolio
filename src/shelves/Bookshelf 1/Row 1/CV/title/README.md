# title/

Drop ONE image in this folder and it becomes the left-hand page of this book
(the page facing you when the book first opens).

- Any of .png .jpg .jpeg .webp
- If there is more than one image here, the first by name wins
- Delete the image and the book goes back to the title-and-blurb page the code
  draws from the project name

It is centre-cropped to the page shape, so it will not be squashed whatever
size you give it. Page proportions are roughly A4 (portrait, about 1:1.42), so
an A4 export fills it exactly. Export at 1600 px wide or more: anything
smaller will look soft once it is on screen.

The build resizes and converts to WebP for you, so put the full-size file here.
