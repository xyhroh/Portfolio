# Row 1 / Row 2

These two folders decide which shelf a book sits on.

  <Shelf>/Row 1/<Your Project>/   -> the TOP row
  <Shelf>/Row 2/<Your Project>/   -> the row BELOW it

Inside a project folder nothing changes:

  <Your Project>/cover/   one cover image (optional)
  <Your Project>/pages/   the page images
  <Your Project>/title/   one image for the left-hand page (optional)

To move a book between rows, drag its whole folder from Row 1 to Row 2
or back. Nothing else needs editing.

Notes
-----
- The old `pages/` folder still works and behaves as Row 1, so books you
  have not moved yet stay where they are.
- Books are laid out left to right in alphabetical order within their row.
- Put more than 8 books on one row and the extras wrap onto the row below.
- The order the chips and the up/down arrow keys walk through is Row 1
  first, then Row 2.
